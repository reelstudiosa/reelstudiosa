# REEL studio — website

Static site, no build step. Open `index.html` in a browser, or drop the whole `site/` folder on Netlify / Vercel / Cloudflare Pages / any static host.

## Structure

```
site/
  index.html          home (showreel hero, reel strip, scroll showcase, studio, services, team, grade lab, contact)
  work/<slug>.html    one subpage per project (shell only; app.js renders the content)
  tools/build-pages.py  regenerates the work/ subpages from data.js
  css/style.css       all styles (dark, cinematic; RTL rules at the bottom)
  js/data.js          ALL CONTENT — every text is {en, ar}; projects, team, services, contact
  js/manifest.js      generated list of stills + extracted colour palettes (don't hand-edit)
  js/app.js           interactions: loader, cursor, carousel, project view, books, grade lab
  assets/img/         WebP images: stills at 2560 (sNN), 1600 (sNN-m) and 640 (sNN-t); posters, novels, team, backgrounds
  assets/video/       web MP4s: full films, 10s muted hover loops, poster frames, showreel.mp4 (hero montage)
```

## Editing content

* Text, names, stats, descriptions → `js/data.js`. Each field has `en` and `ar`.
* Add a project → add an object to `projects` in `data.js`, put its stills in `assets/img/<key>/`
  and add them to `manifest.js` (or re-run the pipeline script below).
* The work strip under the hero loops continuously (drag to scrub, hover to pause). Speed is `0.04` px/ms in `stripFrame` in `js/app.js`.
* Scroll snapping (proximity) applies only to the home-page project chapters.
* Project order on the site = order of the `projects` array in `data.js` (feature, doc, short, ad).
* Team members with a `url` field become links (Hatem → portfolio).
* Default language is English. The toggle (ع / EN) remembers the visitor's choice.
  To default to Arabic change `data-lang="en"` on `<html>` to `ar` and `dir` to `rtl`.
* Before/after grade frames: `grade` list in `data.js`. The "source" images are
  simulated flat versions (`*-log.webp`). Replace them with real ungraded frames if you have them.

## URLs

* Home sections: `#work`, `#studio`, `#services`, `#grade`, `#contact`
* Project subpages: `work/on-the-edge-of-glory.html`, `work/roc-ewc25-jersey-reveal.html`,
  `work/unbearable-to-know.html`, `work/beyond-the-novel.html` (generated by `tools/build-pages.py`;
  re-run it after adding a project to `data.js`). Old `#/work/<slug>` links redirect.
* `?shot=1` renders everything statically (used for screenshots / QA).
* The page background tints to each project's accent while you scroll its chapter on the home page
  (colours in `css/style.css` under `body[data-theme=...]`).

## Hero showreel

`assets/video/showreel.mp4` is a 37 s crossfade of the four projects (10 s each, 1 s fades). The
"Now showing" caption in the hero reads segment starts from `SEG = [0, 9, 18, 27]` in `js/app.js`;
update that array if you re-cut the montage with different timings.

## Regenerating assets

The hero background is `MainBackground.svg` (a PNG inside an SVG) exported as `assets/img/bg.webp`
(2560px), `bg-m.webp` (phones) and `bg-glow.webp` (pre-blurred glow layer). Un-watermarked feature
stills were pulled from the embedded images inside the STILLS SVGs (`still*-clean.webp`).

The source material lives one level up (`../Projects`, `../main-background.jpg`, PDFs).
The image pipeline and video encodes were run with Python (Pillow, PyMuPDF) and ffmpeg
(`pip install pillow pymupdf imageio-ffmpeg`). Headless Chrome rasterised the Figma SVG exports.

## Hosting (Netlify + Namecheap DNS)

1. Deploy: drag the `site/` folder onto https://app.netlify.com/drop (or `netlify deploy --prod --dir=site`).
2. Netlify → Site settings → Domain management → add `reelstudiosa.com` and `www.reelstudiosa.com`.
3. Namecheap → Advanced DNS: A `@` → `75.2.60.5`; CNAME `www` → `<your-site>.netlify.app`.
   Keep the nameservers on Namecheap and leave the SPF TXT / email forwarding untouched.
4. Netlify issues HTTPS automatically once DNS resolves (minutes to a couple of hours).

## Hosting notes

* The short film is published as a 45 s excerpt reel (`short-excerpts.mp4`), not the full film.
  Heaviest files: `jersey.mp4` (~19 MB), `showreel.mp4` (~12 MB). Everything is static-host friendly.
* Fonts load from Google Fonts (Rubik, Aref Ruqaa, Space Mono).
